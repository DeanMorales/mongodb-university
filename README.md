## Kiro Hook: MongoDB Documentation Enhancer

Este proyecto incluye un hook personalizado de Kiro que mejora automáticamente la documentación Markdown con:

- Encabezados estructurados con fecha de actualización
- Índices navegables automáticos
- Conceptos ampliados (500+ caracteres)
- Corrección gramatical
- Referencias y fuentes citadas

### Uso del Hook

1. Abre un archivo Markdown en Kiro IDE
2. Escribe: `mejorar documento`
3. El hook aplicará todas las mejoras automáticamente

Más información en [.kiro/README.md](.kiro/README.md)
